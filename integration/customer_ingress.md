# Entrada de clientes em caixa isolada

`customer_ingress.py` é um receptor temporário para homologação do caminho coletor → n8n → Chatwoot. Ele aceita somente um workflow autenticado do n8n e um recibo de corpo bruto que corresponde ao hash `SHA256(len(instance)[4 bytes] || instance || raw)`. O workflow fixa `workflow_id` e `execution_id` no servidor. O receptor valida o evento `messages.upsert`, o ID nativo, remetente direto, texto e instância. Ele nunca chama um endpoint de mensagem de saída.

O código cria contato, `contact_inbox`, conversa e mensagem recebida em **conta e inbox exclusivos**, usando identificador de contato derivado do SHA256 do endereço. Não grava número, nome nem texto no SQLite; Chatwoot armazena o texto da entrada para revisão humana. O estado `ready` significa somente entrada materializada para futura decisão; não libera resposta. Identidade ausente, opt-out, inatividade ou posse humana produzem `held`. Um ID nativo repetido devolve os IDs existentes; conteúdo conflitante e resultado incerto são retidos sem nova postagem. A coluna `identity` guarda apenas a decisão do resolvedor; no ensaio, todos os dados são fictícios.

Para o ensaio, `directory_file` e `lookup_file` são fixtures fictícias completas. `customer_identity.resolve` é o mesmo resolvedor usado na leitura operacional; a troca futura desses dois leitores exige fontes oficiais e a mesma prova de endereço nativo, sem atribuir LID por suposição. O endpoint recebe `POST /inbound`, `Authorization: Bearer` exclusivo e JSON `{raw_base64,record_id,workflow_id,execution_id}`. A porta é `172.18.0.1:19736`, somente bridge interna do piloto. Não conectar o coletor do Mac, o webhook JP real ou os workflows de envio durante este ensaio.

O bootstrap Ruby cria uma nova conta e caixa na pilha Chatwoot do laboratório. Ele aborta se a conta já existe. A instalação deve preservar o recibo da conta, os IDs do workflow/credenciais e a origem Git/CI no mesmo SHA. O corte futuro deve apontar a fila n8n para este contrato após a prova separada de identidade, posse humana, backpressure e rollback; esta candidata não efetua o corte.
