# Individual manual contact handoff

An operator with the approved personal Chatwoot account can work one existing ticket from a private terminal. The installed Ubuntu command is `sudo /usr/local/sbin/jp-cadastro-manual inspect REQUEST_UUID`. It prompts privately for the personal Chatwoot API token. The local profile must be confirmed, the configured user and email must match, and the account role and access to the specific inbox must still be active. A sudo login alone cannot authenticate the operator.

Use `claim REQUEST_UUID` with the same command after checking the exact customer, original accepted message, phone, desired name version and the current device name. A clean pending task switches to human handling. A task already marked unknown permits observation only. The operator must never repeat an earlier attempt to resolve uncertainty. Duplicate identity, another outstanding task at the destination, open automatic registration or an unresolved identity review retain the ticket.

After checking the contact freshly in WhatsApp Web and the device, run `close REQUEST_UUID`. Enter the observed phone and name independently for each source and a different private evidence reference from each. The central handler binds the two observations to the task and operator, preserves attempt history and reads the persisted ticket back before reporting completion. Submitting invented references cannot substitute for actually performing those observations. The CLI and server have no access to WhatsApp in this flow. Missing or stale evidence leaves the previous result in place.

Both the CLI and the core enforce access. The CLI invokes only Chatwoot profile and inbox reads. Its relay secret stays private on the host and the digest and principal are installed separately in the core. The inner native listener is available only on its own loopback. It uses the native load/save and existing request and task collections. The maintenance rollout requires one reload of the Dell operational core. It does not require reloading Evolution.
